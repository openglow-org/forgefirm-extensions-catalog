# ForgeFIRM extensions catalog

OpenGlow's catalog of extension packages for
[ForgeFIRM](https://docs.forgefirm.org/): a record for each listed version,
each package's author key, and what OpenGlow withdrew. Machines fetch the
signed index built from it, `index-1.ffi`, from this repository's latest
release, and only when their operator asks.

- To list a package, or to see what a listing is and how the catalog is
  kept: [List a package in the catalog](https://docs.forgefirm.org/developers/extension-listing/).
- How a machine verifies the index and judges each listed version:
  [Extension packages](https://docs.forgefirm.org/technical/forgefirm/extensions/#the-signed-index).
